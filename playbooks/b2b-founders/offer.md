# Offer

## What we offer
One or two sentences in the customer's words: the outcome, not the internals.

## Who it is for
The buyer (who pays) and the user (who uses it), if they differ.

## Proof
Only real, shareable facts: named customers, measured results, notable users. If there is none yet, write "no public proof yet" and lean on the specific problem.

## The ask
Exactly one next step, for example: "have 15 min this week to chat about it?"

## Never claim
Things the agent must not say: unreleased features, guarantees, competitor comparisons you cannot back up.
