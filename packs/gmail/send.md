Email goes through the connected Gmail tool. Before the first send, read which account it is signed in as and compare it with the sender in the user's notes.
- Draft mode: create a Gmail draft with the exact reserved text, then receipt `drafted` with the draft id as evidence.
- Send mode: send it, then receipt `sent` with the message id and thread id the tool returns.
- Follow-ups and replies: reply in the stored thread id so they stay in one conversation.
- Reconcile: search the Sent folder for the recipient and subject.
