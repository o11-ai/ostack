Email goes through Outlook on the web in the browser. Before the first send, open Outlook and read the signed-in account; stop if it is not the sender in the user's notes.
- Compose or reply from that account only, pasting the exact reserved text. Follow-ups and replies go in the original conversation.
- After sending, open Sent Items, find the message, and receipt `sent` with its conversation or item id if the URL shows one, or `--evidence "<recipient, subject, sent time>"`.
- If the page errors or the send is unclear, receipt `uncertain`. The next run checks Sent Items before anything is resent.
